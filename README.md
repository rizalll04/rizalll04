## 💊 Medicine Sales Forecasting Website

A web-based **medicine sales forecasting system** designed to analyze historical sales data and predict future medicine demand using the **Triple Exponential Smoothing (TES)** method.

The system helps users analyze sales trends and generate forecasting results that can support inventory and sales planning.

**Tech Stack**

`PHP` `Laravel` `Laravel Blade` `JavaScript` `HTML` `CSS`

**Key Features**

* 📊 Medicine sales data management
* 📈 Sales trend visualization
* 🔮 Sales forecasting using **Triple Exponential Smoothing (TES)**
* 📅 Historical sales analysis
* 📋 Forecasting results
* 📉 Interactive charts
* 💾 Database integration
